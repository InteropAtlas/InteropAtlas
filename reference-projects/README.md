# Reference Projects（参考项目）

本目录记录与 InteropAtlas 方法、数据模型或目标高度相关的外部 Standards Landscape（标准全景）、Knowledge Graph（知识图谱）、Interoperability Framework（互操作框架）、Gap Analysis（缺口分析）等项目。

这些对象不是“被 InteropAtlas 认可的最佳实践”清单，而是研究对象。记录它们的覆盖范围、方法、机器可读性、许可证和可借鉴点，用于反向改进 InteropAtlas。
