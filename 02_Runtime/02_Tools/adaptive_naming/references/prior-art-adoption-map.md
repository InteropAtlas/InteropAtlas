## 公开 prior art 与隐性工作的边界

公开方法经常只披露阶段、原则和客户可见 deliverables，真实内部 SOP 可能包含更多 tacit work。没有证据时不得把推断写成某家公司的既定流程。

当前 Adaptive Naming 对这些“可能由资深人类隐式完成、但 Agent 需要显式化”的工作采用以下原则：

- 若有多家公开线索支持，记录为 synthesis；
- 若只是合理推断，标为 Agent-native operationalization，而不是冒充 prior art；
- 是否进入核心 Skill 取决于它是否跨任务稳定重要；
- 复杂但条件性的工作优先做成按需模块，不让核心流程无限膨胀。
