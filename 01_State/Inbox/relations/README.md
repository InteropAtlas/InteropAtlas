# 候选关系与覆盖视角

这里不是 Canonical 关系目录。`intake-coverage-20260913.yaml` 保存本轮非互斥类别、对象引用和有来源的待审技术关系。

类别归属是 IA 的编辑/导航视角，不是标准作者的规范声明。`proposals` 的技术关系须独立审核；目标包含候选、存在版本条件或正式词表缺词时，不得直接写入 `01_State/02_Relations/`。

Map 是视图入口，Relation 是事实断言；两者不可混同。正式 [Map 入口](../../01_Objects/intake-coverage-map.yaml) 只引用正式对象。Inbox 叠加层由 `intake_coverage_audit.py` 单独生成，不声称已接入通用 Map UI。

本轮 20 个类别是可扩展的发现种子，不是全球完备分类。候选或标准缺失仅表示 IA 尚未覆盖，不能据此声明现实世界存在开放缺口。
