# Standards data

This directory contains structured records for standards, specifications, protocols, APIs, formats, profiles, and related interoperability technologies.

Records in this directory are intended to be factual, machine-readable source data and are dedicated under **CC0 1.0 Universal**, except where explicitly stated otherwise.

Do not copy third-party specification text into this directory unless redistribution rights are clear. Prefer factual metadata, identifiers, relationships, and links to authoritative sources.
