# 03_Evolution

`03_Evolution` 是 InteropAtlas 三个核心一级目录之一。

它承载项目**如何观察自己、学习、验证、决策并改变自己**的内容。

当前二级结构：

```text
03_Evolution/
├── 01_Research/
├── 02_Experiments/
├── 03_Change/
└── README.md
```

- `01_Research/`：研究、分析、Prior Art、Fit Test、Gap/Audit 等；
- `02_Experiments/`：原型、Dry Run、可复现实验与验证；
- `03_Change/`：Proposal、Decision、Migration Plan、Roadmap、Deprecation / Transition 等准备改变项目本身的内容。

原则：Evolution 描述变化过程；一项结果如果被正式采用，应根据其性质进入 `01_State` 或 `02_Runtime`，而不是永久留在 Evolution 中充当正式事实或正式运行源码。
