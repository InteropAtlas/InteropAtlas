# Proposed PR Body

## Summary

Establishes Phase 1 of #122: a stable Knowledge Workspace design baseline before further UI/Schema expansion.

The primary principles document records:
- Canonical Knowledge vs generated representation separation;
- Selection/Perspective before Presentation;
- provisional Perspective → Projection → Workspace vocabulary;
- Wiki/Browse as foundational but non-exclusive;
- multiple Workspaces with cognitive/task justification;
- Human/Agent sharing one Canonical Knowledge world;
- lossy representation with provenance/recoverability protection;
- progressive disclosure;
- decisions vs research hypotheses.

The phase plan records the new sequence:
`principles → systematic research → current-state audit → architecture/Roadmap reset → small real-data experiments → implementation`.

## Scope
Documentation/design only. No Schema, Canonical data, runtime, renderer or generated-site changes.
