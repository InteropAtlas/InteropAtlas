# Shared Organization Vision Context v0.1

> 作用：为 Naming Worker 提供最小、稳定、跨方法共用的 Organization Vision。它不是 Naming Brief，不包含某个方法的具体策略，也不包含 benchmark 设计。

## 1. 命名对象

我们正在为 **InteropAtlas 上层的长期 umbrella organization** 寻找名称。

这个组织不等于 InteropAtlas 本身，也不应被“标准 / 协议 / 地图 / atlas”这些当前项目形态锁死。未来它可以承载多个项目、研究、工具、公共知识工作与新的创造活动。

## 2. 核心愿景

组织关心一个长期循环：

`Commons → Perspective → Creation → Commons ↺`

可用一句话表达：

> Knowledge belongs to the commons; perspective belongs to the individual.

含义不是要求名字逐字编码这些概念，而是说明组织长期存在的价值空间：

- 人类共享知识作为 commons / shared world；
- 个体拥有自己的 perspective / interpretation / lens；
- 个体基于已有知识与自身视角产生 creation / novelty / discovery；
- 新创造又可以回到公共知识空间，成为下一轮的基础。

## 3. 辅助语义

这些属于可探索但非强制表达的长期语义：

- Flow / Connection / Transmission / Relay；
- Transformation / Translation / Representation / Mapping；
- Boundary / Threshold / Frontier；
- Known ↔ Unknown；
- Becoming / Emergence / Discovery。

任何 Worker 都不应把这份列表机械当成必须拼接的词根池。

## 4. 组织级要求

名称应具备成为长期母品牌的可能性：

- 不绑定某个单一产品或当前项目；
- 能容纳未来多个项目与方向；
- 有足够的独立品牌身份；
- 在真实使用中应可读、可说、可传播；
- 可以是 existing word、compound、coined form 或其他适合当前方法的结构；
- 不要求名称自己承担整个组织故事。

## 5. 不在本 Vision 中的内容

以下内容有意不提供给普通 Worker：

- G0–G8 benchmark 的存在与排名；
- 其他方法的流程；
- 历史生成过的候选；
- 哪些候选曾通过或失败；
- `.org` 历史通过率；
- 高频词根 / morphology 统计；
- Owner 对历史候选的具体喜好；
- 最终筛选和评分战略。

这些信息只有在某个角色完成职责确实需要时，才通过对应 Task Packet 单独提供。

## 6. 使用规则

- 本文件可以被所有需要理解 Organization 的 Strategy / Generation / Quality Worker 引用。
- Domain / Registry Screener 等纯技术筛选角色通常不需要读取本文件。
- 方法特有的 Naming Brief / 4Cs / Pivot / Creative Framework 等必须由对应上游 Worker另行生成，不能写回本公共 Vision。
- 正式实验 run 使用时应记录本 Vision 的版本号。
