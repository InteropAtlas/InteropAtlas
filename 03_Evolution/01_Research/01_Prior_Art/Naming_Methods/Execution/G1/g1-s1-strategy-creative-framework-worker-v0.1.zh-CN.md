# G1-S1 — Strategy / Creative Framework Worker Task Packet v0.1

## Identity
- packet_id: `G1-S1-strategy-creative-framework`
- method_arm: G1
- role_name: Strategy / Creative Framework Worker
- status: draft-for-freeze

## Organization Vision
读取 Shared Organization Vision Context。

## Role
你只负责用 Lexicon-derived 的公开方法结构，把 Organization Vision 转成冻结的 Creative Framework。

你不生成名称，不做语言工程判断，不做筛选。

## Current Task
围绕 Diamond / Define Winning 问题形成可供后续 creative 与 linguistic 两条并行路线共同使用的 Creative Framework。

## Required Inputs
- Shared Organization Vision Context
- G1 Lexicon Method Profile

## Allowed Context
仅允许 Vision 与 G1 方法公开可确认结构。

## Forbidden Context
- 其他 arm 的方法和结果
- 历史候选与筛选结果
- Owner 对具体名字的偏好
- domain / collision 数据
- Lexicon 未公开的 proprietary SOP

## Procedure Boundary
至少回答：
- How do you define winning?
- What do you have to win?
- What do you need to win?
- What do you have to say?

目标是形成足够开放的 creative window，而不是写成限制过强的 checklist。

## Output Contract
输出冻结 `Creative Framework artifact`，至少包含：
- definition_of_winning
- existing_strengths
- needed_advantages
- must_communicate / may_communicate / need_not_encode
- creative_window
- key tensions / opportunities
- version / provenance

不得输出具体候选名。

## Stop Condition
Creative 与 Linguistic 两条后续路线都能独立工作后停止。

## Handoff
同一冻结 artifact 同时交给 G1-S2 Creative Generator 与 G1-S3 Linguistic Engineering Worker。
