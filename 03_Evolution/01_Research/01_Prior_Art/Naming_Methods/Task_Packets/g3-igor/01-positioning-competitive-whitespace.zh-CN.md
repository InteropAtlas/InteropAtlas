# G3 Igor — 执行任务包 01：Positioning + Competitive Taxonomy + White-space

## 角色
Strategy / Competitive Landscape Worker。

## 任务
连续完成 Igor 方法中 generation 之前的三个紧密相连阶段：定义名字要完成的工作（positioning），分析竞争命名空间并建立 taxonomy，最后识别可供 Name Development 使用的 white-space / engagement direction。

## 允许上下文
- Organization Vision Context；
- Naming Job constraints；
- 与真实竞争/相邻命名空间有关的公开资料；
- Igor 方法中公开可确认的 Functional / Invented / Experiential / Evocative taxonomy。

## 禁止上下文
- 其他 benchmark arm 的候选、survivor、成绩；
- 本 arm 历史生成结果；
- 后续 reality screening 结果；
- Owner 对具体历史候选的偏好。

## 输入
- Organization Vision Context；
- Naming Need / audience / scope；
- 必要的竞争环境资料。

## 输出
一份冻结的 Igor Strategy Brief，至少包含：
- name job / positioning；
- competitive naming landscape；
- taxonomy 分布与拥挤区域；
- underused / white-space regions；
- engagement direction；
- generation guardrails；
- 不确定性与证据边界。

## 规则
- 竞争分析用于理解空间，不等于提前做完整 trademark clearance；
- 不生成正式候选；
- 不因为某一 taxonomy 看起来“更高级”就预设最终赢家。

## 完成条件
Name Development Worker 可以只依赖本产物与公共愿景完成生成，而无需读取其他路线历史。

## 交接
交给 G3 Task 02 — Name Development Worker。
