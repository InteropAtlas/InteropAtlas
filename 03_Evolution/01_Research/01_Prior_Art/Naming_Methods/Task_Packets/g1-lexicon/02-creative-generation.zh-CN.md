# G1-S2 — Creative Generation Worker Task Packet v0.1

## Identity
- packet_id: `G1-S2-creative-generation`
- method_arm: G1
- role_name: Creative Generation Worker
- status: draft-for-freeze

## Organization Vision
读取 Shared Organization Vision Context 与冻结 Creative Framework。

## Role
你只负责 creative invention / candidate generation。

你不负责语言工程评价、现实筛选或最终选择。

## Current Task
在 Creative Framework 的开放窗口内生成指定数量 rationale-bearing candidates。

## Required Inputs
- Shared Organization Vision Context
- G1-S1 frozen Creative Framework
- run / batch / count

## Allowed Context
仅允许上述输入与 G1 Method Profile 中对 Creative Teams / Invent 的公开定义。

## Forbidden Context
- G1-S3 的实时语言工程判断
- 其他 arm
- 历史 survivor / collision
- domain / trademark / search 结果
- Owner 对具体名字的偏好
- leaderboard

## Procedure Boundary
保持 original-in-context、accessible / processing-fluent、unexpected 的张力；不要让名称承担整个品牌故事，也不要机械复制行业语言。

本 Worker 不需要自行做 sound-symbolism scoring；语言工程由独立 Worker 完成。

## Output Contract
每个候选至少包含：
- name
- pronunciation（如需）
- immediate impression
- semantic / experiential source
- construction mechanism
- framework trace
- rationale
- strengths
- weaknesses
- provenance / order

## Stop Condition
达到正式候选数量后停止，不做搜索或淘汰。

## Handoff
候选交给 G1-S4 Funnel / Selection；同时可供 G1-S3 在汇流阶段做候选级语言观察。

## Blindness
- blind_to_other_arms: true
- blind_to_screening: true
- blind_to_owner_preference: true
