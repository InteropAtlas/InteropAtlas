# G7 NameStormers — 执行任务包 04：Pitch / Context

## 角色
Pitch / Context Worker。

## 任务
把通过 Prescreen 的候选放入真实品牌语境中呈现，形成简洁 rationale、tagline / context hook 与应用场景，帮助 Feedback / Test Worker理解候选，而不是只看裸字符串。

## 允许上下文
- Organization Vision Context；
- G7 Task 01 Strategy Brief；
- G7 Task 02 候选 rationale；
- G7 Task 03 Prescreen 结果。

## 禁止上下文
- 其他 arm 候选与成绩；
- 后续 feedback / test 结果；
- Owner 对其他路线候选的偏好；
- 在本阶段生成新名称。

## 输入
通过 Prescreen 的候选。

## 输出
每个候选的 Pitch Card：
- name；
- one-line rationale；
- contextual story；
- optional tagline / usage example；
- intended pronunciation；
- known risk summary；
- 不夸大、不掩盖弱点。

## 规则
- Pitch 用于解释，不用于给弱名字“包装加分”；
- 保留裸字符串表现与上下文表现的区别；
- 不重新生成。

## 完成条件
形成可供独立 Feedback / Test Worker 使用的统一呈现材料。

## 交接
交给 G7 Task 05 — Feedback / Test Worker。
