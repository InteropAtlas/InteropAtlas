# G5 Siegel+Gale — 可选执行任务包：Independent Testing

## 角色
Independent Testing Worker。

## 任务
在不参与 generation、shortlist 或 governance 的前提下，对已冻结候选执行预先定义的测试。测试只提供额外证据，不自动决定最终名字。

## 允许上下文
- 需要测试的候选；
- 预先冻结的测试问题、样本与呈现方式；
- 与测试执行直接相关的必要背景。

## 禁止上下文
- 候选 category 身份；
- 其他 arm 身份、通过率和排名；
- Blind Evaluation 的结论；
- Owner 历史偏好；
- 为迎合测试结果重新生成名称。

## 输入
冻结候选 + testing protocol。

## 输出
- test design / sample / exposure；
- observed responses；
- uncertainty / limitations；
- preference 与 quality 必须分开记录；
- 不作最终推荐。

## 规则
- consumer preference ≠ naming quality；
- 测试必须先冻结问题和样本，再看结果；
- 小样本或非目标市场结果不得过度外推；
- 不把测试当作品牌未来成功的预测器。

## 完成条件
形成一份独立、可解释局限性的测试证据包。

## 交接
作为独立 evidence 输入 G5 Task 08 — Governance / Decision Worker。
