# G6 Tungsten — 执行任务包 01：Pivot Point + Evergreen Strategy

## 角色
Pivot / Evergreen Strategy Worker。

## 任务
识别组织长期不会轻易变化的 Pivot Point，并把它转成可供母品牌命名使用的 evergreen umbrella concept。此阶段不生成正式名称。

## 允许上下文
- Organization Vision Context；
- Naming Job constraints；
- 组织长期定位、未来扩展方向与已知产品/项目结构。

## 禁止上下文
- 其他 arm 候选、成绩、筛选结果；
- 本 arm 历史 survivor 作为模板；
- reality/domain collision 统计；
- Owner 对具体历史候选的偏好。

## 输入
Organization Vision Context + Naming Need。

## 输出
冻结的 Pivot / Evergreen Brief，至少包含：
- enduring principle / value proposition；
- what is likely to change vs not change；
- umbrella concept；
- future naming architecture needs；
- what the parent name must not be locked to；
- unresolved tensions。

## 规则
- Pivot Point 不能等同于当前产品功能；
- evergreen 不等于抽象到毫无内容；
- 不提前测试具体名字；
- 若存在多个 plausible pivot，应记录 trade-off，而不是在本阶段强行创造名称验证。

## 完成条件
形成足够稳定、可供 Parent Name Development 使用的母品牌战略输入。

## 交接
交给 G6 Task 02 — Parent Name Development Worker。
