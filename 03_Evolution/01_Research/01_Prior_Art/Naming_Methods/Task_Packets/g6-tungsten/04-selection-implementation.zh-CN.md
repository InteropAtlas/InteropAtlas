# G6 Tungsten — 执行任务包 04：Selection / Implementation

## 角色
Selection / Implementation Worker。

## 任务
汇总 Pivot fit、evergreen potential 与 Architecture Stress-test，形成 G6 路线内部的候选选择建议与实施说明。此阶段不重新生成名字。

## 允许上下文
- Organization Vision Context；
- G6 Task 01 Pivot / Evergreen Brief；
- G6 Task 02 候选 rationale；
- G6 Task 03 architecture results；
- 必要的统一现实筛查结果。

## 禁止上下文
- 其他 arm 候选、成绩与排名；
- benchmark leaderboard；
- Owner 对其他路线候选的偏好；
- 在本阶段现场创造 replacement names。

## 输入
G6 Task 01–03 的结构化产物。

## 输出
- 推荐保留候选；
- Pivot / evergreen / architecture trade-offs；
- implementation considerations；
- 不建议保留候选及理由；
- 是否进入统一 Quality / Owner Gate。

## 判断原则
- architecture fit 只是关键维度之一，不自动覆盖 pronounceability / distinctiveness / brand quality；
- 不因某个名字能组成很多子品牌就自动判定为好名字；
- 若没有足够好的候选，可以明确返回 none。

## 完成条件
形成可审计的 G6 路线内部选择记录。

## 交接
交给共用 E3 Quality / Pareto Reviewer；必要时 E5 Owner Exposure。
