# G6 Tungsten — 执行任务包 02：Parent Name Development

## 角色
Parent Name Development Worker。

## 任务
依据冻结的 Pivot / Evergreen Brief 发展母品牌候选。目标是形成能承载未来项目、产品族和组织扩张的 parent / corporate name，而不是描述当前单一项目。

## 允许上下文
- Organization Vision Context；
- G6 Task 01 的 Pivot / Evergreen Brief；
- 当前候选数量与输出格式。

## 禁止上下文
- 其他 arm 候选与成绩；
- reality/domain/trademark 结果；
- 本 arm 历史 survivor 作为模板；
- Owner 对具体历史候选的偏好。

## 输入
冻结的 Pivot / Evergreen Brief。

## 输出
正式母品牌候选，每个候选至少包含：
- name；
- intended pronunciation（如需要）；
- relation to Pivot Point；
- why it is evergreen；
- likely shorthand / naming-family potential；
- strengths / risks；
- provenance。

## 规则
- 不在本阶段做 architecture stress-test 结论；
- 不生成明显绑定当前单一项目/产品的名字；
- 不搜索现实占用；
- 不为了易扩展而机械产生相同后缀家族。

## 完成条件
形成冻结候选集，足以交给独立 Architecture Stress-test。

## 交接
交给 G6 Task 03 — Architecture Stress-test Worker。
