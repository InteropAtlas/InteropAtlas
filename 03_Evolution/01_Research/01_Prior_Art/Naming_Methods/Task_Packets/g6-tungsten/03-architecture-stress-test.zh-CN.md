# G6 Tungsten — 执行任务包 03：Architecture Stress-test

## 角色
Brand Architecture Stress-test Worker。

## 任务
只测试冻结的 parent-name 候选是否能支撑未来命名架构，不修改名字、不重新生成。检查 masterbrand / project / product / tool / research / acquisition 等不同层级的承载能力。

## 允许上下文
- 冻结候选；
- Organization Vision Context；
- G6 Task 01 的 architecture needs；
- 预先定义的 architecture probes。

## 禁止上下文
- 其他 arm 候选和成绩；
- reality/domain/trademark 结果；
- Generator 原聊天历史；
- 为通过测试而现场改名。

## 输入
G6 Task 02 的冻结候选。

## 输出
每个候选的 architecture test：
- `[Name] / InteropAtlas`；
- `[Name] Research`；
- `[Name] Commons`；
- `[Name] Tools`；
- 可选的未来项目 / 子品牌 / offering probe；
- extensibility strengths；
- awkwardness / lock-in risks；
- Pass / Yellow / Red（仅 architecture 维度）。

## 规则
- Architecture fit ≠ overall naming quality；
- 不因某一 probe 不自然就自动全盘淘汰，除非暴露结构性问题；
- 不重新生成或修补名字；
- 不引入现实碰撞信息。

## 完成条件
每个候选都有可比较、可审计的架构承载结论。

## 交接
交给 G6 Task 04 — Selection / Implementation Worker。
