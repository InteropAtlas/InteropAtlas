# Human-AI Collaboration V0 Checklist

> 实验性 checklist，用于后续验证 IA 的开放协作流程是否同时适合人类和 Agent。

每个候选任务至少检查：

- [ ] 任务目标和完成条件对普通人可读；
- [ ] 当前是否已有主要执行者；
- [ ] 执行者是 Human 还是 Agent 不改变任务本身的语义；
- [ ] Agent 是否有权限执行该任务；
- [ ] 执行结果是否通过 PR 暴露给其他参与者；
- [ ] 是否存在独立 Review / Oversight；
- [ ] 任务失败或执行者失联后是否可以重新开放；
- [ ] 自动化机制没有把人类贡献者排除在正常流程之外。

当前不要求：自动 Lease、Heartbeat、自动目标生成、多 Agent 辩论。
